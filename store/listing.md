App Cloner — Multi App Clone

## Short description (max 80 chars)
Clone any app, run multiple accounts side by side. No root required.

## Full description
App Cloner lets you create independent copies of your favourite apps so you can
run multiple accounts at the same time — one phone, two (or more) logins. No
root required.

Features
- Clone almost any installed app with a different package name and separate data
- Multiple clones of the same app (Clone 1, Clone 2, …)
- Split APK / App Bundle support (WhatsApp, Instagram, and more)
- Custom clone names and icons (Premium)
- Batch cloning — clone several apps at once (Premium)
- Backup & restore your clone configurations
- Stealth & anti-detection options
- Dark, modern Material 3 interface

Free vs Premium
- Free: up to 3 clones, ad-supported
- Premium (one-time): unlimited clones, ad-free, batch cloning, custom icons

Notes
- Some apps that verify their own signature (e.g. banking apps) may not run as
  clones.
- Apps that rely on Google Play Services may require a separate Google account
  on the clone for push notifications and login.
